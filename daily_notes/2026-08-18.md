Bygul investigation:
- There was an issue with the data that there were low precision across all tools. After investigating, I discovered that the wgsim was introducing mutations directly to the amplicon templates before being amplified, so there would be mutations that were truly there, but because of a mutation that was not accounted for
- I fixed the simulator to use 0 for this value (default was using this)

Then the issue was some of the samples were probably a bit too difficult (20 genomes random mutations), so updated the genomes to be real RSV-A genomes
